# customer-registration-form-csharp

Aplicação desktop desenvolvida em C# para cadastro e gerenciamento de clientes por meio de uma interface gráfica para Windows.

## Sobre o Projeto

Aplicação desktop desenvolvida em C# para cadastro e gerenciamento de clientes por meio de uma interface gráfica para Windows.

## Tecnologias Utilizadas

- C#
- .NET Windows Forms (ou tecnologia de interface efetivamente utilizada)
- ADO.NET / Dapper (conforme implementação)
- SQL Server

## Funcionalidades

- Interface gráfica para preenchimento dos dados do cliente
- Validação de campos obrigatórios e CPF, quando implementada
- Ações para salvar, limpar e excluir registros
- Exibição dos clientes em grade de consulta

## Arquitetura do Projeto

Aplicação desktop organizada conforme a estrutura adotada no código-fonte. O levantamento descreve uma abordagem de camada única ou MVVM; mantenha no README apenas o padrão que estiver realmente implementado.

## Banco de Dados

SQL Server

## Como Executar

1. Clone este repositório.
2. Abra a solução no Visual Studio.
3. Configure a conexão com o SQL Server conforme os parâmetros do ambiente.
4. Crie ou restaure a estrutura do banco de dados utilizada pela aplicação.
5. Restaure as dependências, compile e execute o projeto.

## Aprendizados

- Desenvolvimento de aplicações desktop para Windows.
- Construção de formulários e tratamento de eventos da interface.
- Validação de dados de entrada.
- Integração com banco de dados relacional.
